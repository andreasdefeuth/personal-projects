# DBU Scraper

The purpose of this project is to automate data collection from DBU tables to simple text format

This is to make life easier for graphic creation in Photoshop with updated tables, without having to manually copy/paste data

Simply load the .ipynb into Google Colab or VSCode, replace url and run it

For JS, it will be necessary to initiate the project (npm init -y) and install axios cheerio docx (npm install axios cheerio docx)
